# Symbols App Review rejects as non-public or deprecated API (Guideline 2.5.1), checked by appstore_lint.py against
# the undefined symbols (`nm -m -u`) of every Mach-O file in the app. One entry per line:
#   <symbol or glob>  [from=<library>]   # source
# A glob ends in * (prefix match). from=<library> limits the entry to symbols bound to that library (two-level
# namespace, as nm prints "(from Accelerate)"); without it the symbol is refused whatever it binds to.
# Besides this list, appstore_lint.py refuses every BLAS / LAPACK-shaped symbol imported from Accelerate that is not a
# documented entry point (rule in appstore_lint.py: accelerate_kind) - the explicit list below is what App Review
# named, so the rule and the list check each other.
#
# A longer, community-maintained list of Accelerate symbols App Review flagged:
#   https://github.com/ipsupport-llc/llmtray (scripts/appstore/deprecated_accelerate_symbols.txt, PR #260)
# (referenced, not copied).
