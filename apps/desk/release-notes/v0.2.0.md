## Reelfold 0.2.0 · 千剪 0.2.0

The first public release of Reelfold: one recording, folded out into every cut for every platform. Describe the job
in one sentence, drop the footage, and Reelfold plans it, runs a pilot, then makes the clips, captions, covers and
post copy, and asks you only when it needs a decision.

### Highlights

- **Home composer and plan card**: one sentence plus your footage becomes a plan with an estimate; a pilot runs
  before the full batch. A built-in sample recording lets you try it in minutes, with or without an AI account.
- **Projects and Inbox**: many clips in parallel; the Inbox shows only what needs you.
- **Chat-first clip editor**: a big player, edits proposed as cards, a timeline with a scrub bar, transcript cuts,
  undo of one earlier step, before/after compare, and "edit with AI" across a whole project.
- **Publishing**: 20 platform profiles (YouTube, TikTok, Instagram, X, LinkedIn, 小红书, 抖音, 视频号, B站 and more),
  a week board that lays out a week of posts, and assisted upload pages you publish yourself (never auto-posts).
- **Your own AI**: sign in with a Claude Code or Codex subscription, use an API key (Anthropic, OpenAI or any
  OpenAI-compatible server) or a local model, with a fallback chain per task.
- **Engine**: recipes for talking heads, lessons, interviews / podcasts, launch kits and more; bilingual captions;
  named-entity checks after speech recognition (宏都拉斯 → 洪都拉斯); studio sound and a license-free music library.
- **Languages**: the app in English, 中文 and Français; docs at [reelfold.com/docs](https://reelfold.com/docs/).

### 亮点（中文）

- 一句话 + 素材：自动出方案和预估，先试跑再批量；内置示例素材，不连 AI 也能几分钟上手。
- 多个片段并行，收件箱只显示需要你决定的事。
- 对话式剪辑：大播放器、改动以卡片呈现、时间线、按字幕删词、撤销任意一步、前后对比，整个项目一起「用 AI 改」。
- 20 个平台规格（小红书、抖音、视频号、B站、YouTube、TikTok 等），一周发布看板，辅助填写上传页，由你自己点发布。
- 用你自己的 AI：Claude Code / Codex 订阅登录、API key 或本地模型，按任务回退。
- 识别后的专有名词校对（宏都拉斯 → 洪都拉斯）、双语字幕、录音棚音质、免版税音乐库。

### Install

- **macOS (Apple silicon, macOS 14+)**: download `Reelfold-0.2.0-mac-arm64.dmg` below, open it and drag Reelfold to
  Applications. The app is signed with a Developer ID and notarized by Apple, so it opens without warnings, and it
  updates itself. Intel Macs are not supported by this build.
- **Windows 10 / 11 x64 (preview, unsigned)**: download `Reelfold-0.2.0-win-x64-setup.exe` below and run it (per-user
  install, no admin rights needed). Windows support is new and less tested than the Mac app
  ([install on Windows](https://reelfold.com/docs/start/install-windows/)). The installer is **not code-signed**, so
  SmartScreen shows "Windows protected your PC": choose More info → Run anyway, and only run installers downloaded
  from this repository's Releases page. The app checks this release feed for updates (`latest.yml`); Windows updates
  are new, so if one fails, download the next installer from Releases.

**macOS**：下载下方 `Reelfold-0.2.0-mac-arm64.dmg`（Apple 芯片，macOS 14 及以上），已用 Developer ID 签名并经 Apple
公证，可自动更新。**Windows**（预览版，未签名）：下载下方 `Reelfold-0.2.0-win-x64-setup.exe` 运行即可（安装到当前用户，无需管理员
权限），适用于 Windows 10 / 11 x64。Windows 版刚推出，测试不如 Mac 版充分。安装包**未做代码签名**，SmartScreen 会提示
「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」；请只运行从本仓库 Releases 页面下载的安装包。应用会通过本发布的
`latest.yml` 检查更新；Windows 自动更新是新功能，若更新失败，请从 Releases 下载新版安装包。
