## Reelfold 0.2.3 · 千剪 0.2.3

Tidy up All projects: archive what you no longer need, get it back any time.

### Highlights

- **Archive projects**: "Remove from list" is now **Archive** in a project's menu and in bulk select, with Undo.
- **Archived tab**: archived projects, dimmed with their archive date; **Restore** one or many. Search and type
  filters work there too, and an archived project still opens. Nothing on disk is deleted, and a project with a run
  going is never archived.
- Fixes: the promo build works without the subset fonts installed; no false "problem in the app" when the engine
  starts after the window.

### 更新（中文）

- 项目归档：项目菜单和多选里的「从列表移除」改为「归档」，可撤销。
- 「已归档」标签页：显示归档的项目和归档日期，可单个或批量「恢复」；搜索和类型筛选同样可用，归档的项目也能打开。不会删除任何文件，正在运行的项目不会被归档。
- 修复：未安装字体时宣传片也能合成；引擎晚于窗口启动时不再误报「出了问题」。
