## Reelfold 0.2.3 · 千剪 0.2.3

Everything since 0.2.1: a watermark on every export, project archiving, a richer promo template, a leaner and
safer Mac app (the same build is in the Mac App Store review), and many fixes from real edits.

### Highlights

- **Watermark**: your handle, a generated logo or your own PNG on every export, placed inside each platform's safe
  area and above the captions (Settings › Watermark; off for one video from the Export card).
- **Archive projects**: "Remove from list" is now **Archive**, with Undo, an **Archived** tab and **Restore**.
  Nothing on disk is deleted.
- **Promo template, less talking head**: screen recordings full screen with you as a small tile, animated data
  cards, hooks, b-roll highlights, browser bars cropped automatically, platform bitrates.
- **See what is happening**: the plan card shows real progress; plans and their questions follow the app's language.
- **Leaner, safer app**: the engine talks to the app over a private Unix socket instead of a local network port; the
  bundled Python no longer carries tkinter or scipy; the app is far smaller.
- Fixes: post copy is drafted even without an AI; the sign-in terminal no longer loses the CLI's first lines;
  covers no longer warp faces; Chinese quotes no longer show as boxes; the Windows engine starts again.
- Signed with a Developer ID and notarized by Apple (macOS, Apple silicon); Windows x64 is an unsigned preview.

### 更新（中文）

- 水印：每条导出视频自动加上你的账号名、生成的 logo 或你自己的 PNG，自动避开各平台的界面区域和字幕（设置 › 水印；单条视频可在导出卡片里关掉）。
- 项目归档：「从列表移除」改为「归档」，可撤销；新增「已归档」标签页，可恢复。不会删除任何文件。
- 作品宣传模板：录屏全屏 + 小头像、数据动画卡、开头 hooks、素材精选、自动裁掉浏览器栏、按平台码率导出。
- 出方案时显示真实进度；方案和问题跟随应用语言。
- 更轻更安全：引擎和应用之间改用私有的 Unix socket，不再占用本地网络端口；内置 Python 去掉 tkinter 和 scipy，安装包小了很多。
- 修复：没有 AI 也能生成发布文案；登录终端不再丢失开头的输出；封面不再拉变形；中文引号不再显示成方框；Windows 版引擎恢复正常启动。
- macOS（Apple 芯片）已签名并经 Apple 公证；Windows x64 为未签名预览版。
