你会得到从播客、访谈或通话录像里截出来的短视频切片：挑出最精彩的片段，做成竖屏或三人版式，带字幕、hook 和记笔记面板。不想露脸的嘉宾，脸上会盖一个跟着人脸走的贴纸（比如放个小猫），而且每一帧都检查过有没有盖住。

![三人通话切片联系表：上方两位嘉宾的脸盖着小猫贴纸、名字标签已打码，下方是主持人，配有标题、高光预告角标、记笔记面板和字幕](../../../../assets/shots/call-clips.jpg)

## 开始之前

- **一段录像**：Zoom、Google Meet、Teams 的会议录像，或视频播客。宫格视图最好，每个人始终在固定的小窗里。
- **谁是谁**：哪个窗口是你（不遮），哪些嘉宾要遮。
- **嘉宾的同意**。贴纸只遮住脸，遮不住声音、说出口的名字、公司，或对前东家的评价。发布前请和出镜的人确认。
- **不想被听到的名字**。嘉宾录到一半常会说「这段剪掉」，而一个说出口的名字就能让贴纸白遮。

## 在 Mac 应用里

1. 在首页输入框里说清楚，把录像拖进来，比如「这期访谈切 5 条竖屏，把嘉宾的脸遮一下」。
2. **方案**里写明版式、遮哪些窗口、切几条、每条多长、发哪些平台。
3. **审核选段**。千剪（Reelfold）只转写一遍，提出最精彩的几段，每段配好标题和 hook。保留、删除或调整都可以。
4. **嘉宾同意**。应用会请你确认嘉宾同意发布（露脸或遮脸）。这件事永远由你来定。
5. **批量**开始：逐条剪辑，压短气口、去掉口头禅，跟踪每张要遮的脸并贴上贴纸，把会议软件里的名字标签打码，排好窗口，烧录字幕。
6. **遮脸检查**。每条嘉宾跟踪轨都会做几何检查：贴纸必须 100% 的帧都盖住脸。低于 100% 就亮红灯，这条不会继续。
7. 审片，然后每条单独发布，最后由你按下发布。

## 用 Claude Code 技能

告诉 Claude 这是什么录像、要遮谁，是挑几段高光，还是把整场对话首尾相接切成一条条。技能按 `workflows/call-clips` 来做，它会：

- 量出窗口布局，从名字标签、你的自我介绍、谁在主持来判断哪个窗口是你；几个信号对不上时会先问你；
- 弄清楚每一段到底是谁在说，绝不把别人的话安到你头上；
- 选段之前先在逐字稿里搜名字和「剪掉」之类的请求；
- 给你一张去口癖审阅单，你回一句 `确认 3,5 / 保留 7` 就行；
- 覆盖率检查没有打印 100% `PASS` 的切片，不会交付。

不要靠在成片里重新检测人脸来验证遮挡：检测器会把卡通贴纸的眼睛当成人脸，每一帧都报有人脸。覆盖率检查才是验证。

## 版式

| 版式 | 画布 | 人数 |
|---|---|---|
| 竖屏（默认） | 9:16 | 两个窗口上下排，遮一位嘉宾或都不遮。 |
| 三人 | 9:16 | 三个窗口。指定平台时是舞台版式：谁在说话谁放大，另外两人在下面。 |
| 横屏 | 16:9 | 两人或三人并排，可以做双语字幕。目前只在技能里可用。 |

## 值得知道的选项

| 选项 | 默认 | 作用 |
|---|---|---|
| 要遮的嘉宾 | 无 | 每位嘉宾的窗口区域、显示名和贴纸（小猫、小狗，或你自己的图）。 |
| 不遮脸 | 关 | 只有所有人都同意露脸时才打开。 |
| 名字打码 | blur | `blur` 模糊、`cover` 纯色盖住、`off` 不处理。在裁切之前作用于原画面。 |
| 剪口癖力度 | classic | `classic` 保留换气和稍长的停顿；`word`、`tight` 剪得更狠。 |
| 切片条数 | 5 | 默认每条 30 到 90 秒。 |
| hook | 两段短高光 | 放在开头，稍快播放，带「高光预告」角标。 |
| 发布平台 | 小红书 9:16、抖音 | 字幕、标题、面板和窗口都会挪进各平台的安全区。 |

## 示例指令

- 「这期播客截最精彩的几段做竖屏，左边是嘉宾，脸上放个小猫，名字打码。」
- 「三个人的会议录像，两位嘉宾都遮脸，用三人版式，谁说话谁大。」
- 「整场对话首尾相接切成几条，只去掉卡顿。」
- 「再检查一下第 2 条贴纸有没有一直盖住嘉宾，把她说公司名字那段剪掉。」
