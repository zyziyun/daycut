你会得到一条精致的宣传片，素材是你介绍自己作品（或推荐某样东西）的口播：剪得很紧，人像滑到一侧和 3D 截图卡片左右分栏，卡片滚动到你正在讲的位置，配荧光笔划线；画面定格，从截图里放大出一张提示词卡片；镜头推进一个带边框的屏幕，播放精选片段；还有章节进度条、片尾卡、封面和发布文案。默认 16:9，也能按平台排出竖屏版。

## 开始之前

- **口播录像**：一段你讲这个作品的录像。
- **截图**（PNG 或 JPG）：你提到的页面、帖子、文档或 App 界面。长截图也行，会滚动。
- **精选片段（可选）**：一段要插进去的短视频。
- **链接**放进文案，有标题的话也一起给。

## 在 Mac 应用里

1. 在首页输入框里描述这条宣传片，把口播、截图和精选片段拖进来。
2. **方案**里写明横屏还是竖屏、发哪些平台、渲染质量。
3. **保留片段**。正文和结尾各留哪些句子。可以让 Agent 先根据逐字稿提一版。
4. **确认去 filler**。嗯、呃和结巴已经删了，可能是实词的等你确认。
5. **素材与高亮位置**。哪张截图什么时候出现、哪几行划荧光笔、在哪里定格、精选片段放什么。这是创作决定，永远由你来定。
6. **批量**生成宣传片、渲染、统一响度，并做好封面和文案。审片后发布。

## 用 Claude Code 技能

把文件夹交给 Claude，描述你要的宣传片。技能按 `workflows/promo-recut` 来做，所有内容相关的设置都在一个 `promo.config.yaml` 里：

1. 转写口播，把保留片段对齐到词边界，给你一张去口癖审阅单，你回 `确认 3,5,9 / 保留 7` 这样一句。
2. 剪完后重新转写，确认没有误删实词。
3. 测量每张截图里的文字行，荧光笔落在真实的行上，不靠猜。
4. 生成 HyperFrames 项目，在转场进行到一半时截几张图给你检查，再完整渲染。
5. 渲染，导出到 −14 LUFS，写好封面和带章节时间线的文案。

```bash
python3 $VSTUDIO/workflows/promo-recut/scripts/build_promo.py promo.config.yaml --platform douyin
```

这条命令为某个平台生成竖屏版式。16:9 宣传片不会直接裁成 9:16，否则分栏和卡片会被切掉。

## 剪辑里有什么

| 效果 | 作用 |
|---|---|
| 左右分栏 | 人像滑到一侧（竖屏是上方条带），另一侧是截图卡片。 |
| 3D 截图卡片 | 卡片滚动到你正在讲的地方，用荧光笔和红框标出重点行。 |
| 标签和关键词字幕 | 小标签，以及关键词高亮的字幕。 |
| 定格放大 | 口播在某一帧定住，从截图里放大出一张提示词卡片。 |
| 推进精选片段 | 镜头推进一个带边框的屏幕，播放你的精选片段。 |
| 章节进度条、印章、片尾卡 | 带章节名的进度条、结尾印章和收尾卡片。 |

## 值得知道的选项

| 选项 | 默认 | 作用 |
|---|---|---|
| 横屏 / 竖屏 | 横屏 | 横屏 16:9，或按平台安全区排的竖屏。 |
| 发布平台 | YouTube | 第一个平台决定版式。竖屏可选小红书 3:4 或 9:16、抖音、TikTok、Shorts、B站竖屏。 |
| 渲染质量 | delivery | `draft` 草稿、`looks` 看效果、`delivery` 交付。 |
| 封面修图 | 开 | 封面人像会修图；想保留原样就关掉。 |

## 示例指令

- 「用这段讲我 App 的录像做一条 16:9 宣传片，三张截图都用上，演示视频作为精选片段插进去。」
- 「讲到价格时，在第二张截图那一行划荧光笔；1 分 20 秒左右在提示词那里定格放大。」
- 「再做一版竖屏，发抖音和小红书。」
- 「封面裁到我的手了，换一帧。」
