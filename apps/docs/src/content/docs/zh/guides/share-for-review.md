title: 分享审片
description: 给学员、客户或合作方发一个审片网页，对方逐条点「通过」或「需要修改」，意见回到你的收件箱。不托管、不追踪。
---

发布之前，常常要别人先看一眼：学员看自己的课程切片，客户确认这一周的内容，合作方看联名视频。**分享审片**会生成一个小网页，对方用任何浏览器打开。每条片子都能看到视频、标题、各平台版本和发布文案，然后点 **通过** 或 **需要修改** 并写一句意见。意见会作为收件箱条目回到你这里。

这个网页就是你电脑上的一个文件夹。千剪不会上传、托管它，也不会追踪谁打开过。

## 对方收到什么

一个文件夹，双击 `index.html` 打开：

```
Week-12-review-6a4d40/
├── index.html      网页：播放器、标题、版本、文案、通过 / 需要修改
├── review.json     同样的数据，给程序读（不含你电脑上的文件路径）
├── media/          压缩后的预览视频（H.264，540p / 720p / 1080p）
├── posters/        每条一张封面（有封面就用封面）
├── captions/       每条的发布文案，纯文本
└── README.txt      怎么打开
```

旁边还有一个同名的 `.zip`。网页可以离线使用，不发出任何网络请求，没有统计代码，也不从别处加载字体或脚本。对方的选择会先保存在他自己的浏览器里，直到他发给你。

## 在 Mac 应用里

1. 打开项目，点 **分享审片**。片子的右键菜单、剪辑页顶栏（分享图标）和交付包页面里也有这个入口。
2. 选择包含哪些片子：做好的片子默认全选，不想给对方看的取消勾选。
3. 选 **画质**：小（540p，发送最快）、标准（720p，默认，手机上看足够）、高清（1080p）。
4. 可以改页面标题，写上你的名字（「来自……」）和一句话，比如「请在周五前回复」。
5. 页面底部的 **由 Reelfold 制作** 默认打开，只是一个指向 reelfold.com 的链接，可以关掉。开关与否，页面都没有任何追踪。
6. 点 **生成审片页**。完成后会显示文件夹和压缩包，可以 **在访达中显示**。

### 隐私检查

如果片子里有别人出镜，生成之前对话框会提示：打码的嘉宾（访谈、播客切片，或你在剪辑页加的隐私贴纸）、没有每一帧都盖住的遮脸、需要嘉宾同意、被隐藏的屏幕区域。出现警告时，必须勾选「出镜的人都同意给对方审片」才能分享。预览视频是从成片压缩来的，打码也一样保留。

## 意见怎么回来（不需要服务器）

对方在网页上看完每条，点 **通过** 或 **需要修改**，写清楚要改什么（「0:12 字幕挡住了脸」），填上名字，点 **发送我的意见**。有三种方式发给你：

- **复制** 一段短的反馈码（`RFB1.…`），粘贴到任何聊天里；
- **发邮件**，自动打开邮件 App，附上摘要和反馈码；
- **下载文件**，保存一个 `.reelfold.json`，作为附件发过来。

在千剪里打开 **收件箱**，点 **导入反馈**。粘贴反馈码，或者直接粘贴整封邮件（即使邮件 App 把反馈码折成了几行，也能找出来），或者把 `.reelfold.json` 拖到对话框里。每条意见变成一个收件箱条目：

- **通过** → 一条「标记为可发布」。片子显示为已通过，可以排期。
- **需要修改** → 一条会打开剪辑页的条目，意见固定在顶部；意见也会留在这条片子的对话里，可以直接让 AI 改。

同一份反馈导入两次不会重复。收件箱提示里的「撤销」可以撤回「标记为可发布」。

## 怎么发出去（托管方式由你决定）

千剪不会把你的片子放到网上。把网页交给对方的方法：

- **发压缩包**：微信、邮件、隔空投送都行。对方解压后打开 `index.html`。
- **上传文件夹**到你自己的网盘（Google Drive、Dropbox、OneDrive 等）再分享。`index.html` 要和 `media/`、`posters/` 放在一起。大多数网盘能预览视频，但不能运行网页，所以对方需要把文件夹下载下来再打开 `index.html`。
- **放到你自己的网站**：它就是一个静态文件夹，任何静态托管都可以。

分享出去的页面不会自动过期。审完之后，删掉文件夹（和上传的副本）即可。

## 命令行

```bash
python -m vstudio.project share --dir ~/Videos/week-12 --quality standard --title "第 12 周" \
  --owner-name "Ziyun" --expiry-note "请在周五前回复"      # --no-footer、--no-zip、--outputs a,b
python -m vstudio.project share --dir ~/Videos/week-12 --scan       # 只看隐私提示
python -m vstudio.project feedback import --file feedback-1a2b3c4d.reelfold.json   # 或 --text 'RFB1.…'
python -m vstudio.project feedback list --dir ~/Videos/week-12
python -m vstudio.project feedback resolve --dir ~/Videos/week-12 --id <条目>      # 通过 -> 可发布
```

同样的片子和选项，每次生成的文件完全一样。对应的库是 `vstudio.project.share`（`share`、`build_page`、`privacy_scan`、`parse_feedback`、`import_feedback`）。
