---
title: 课堂切成知识点
description: 把一节课的录像按知识点切成短视频：一个短语、一个单词、一条规则或一个易错点一条，每条有「今日短语」标题卡、关键词卡片和中英字幕，另附本课回顾和学习笔记。
---

给每周都要录课的老师、家教和教练。交一节 60 分钟的课，得到的是按**知识点**切出来的短视频，而不是按时长硬切：「今日短语：break the ice」「易错点：I am agree → I agree」「今日词汇：reluctant」。每条以标题卡开头，保留老师自己的讲解和例句，关键词第一次出现时弹出卡片，字幕是课堂原文加一行译文。另外还有一条把所有知识点串起来的回顾，以及这节课的学习笔记（Markdown 和 PDF）。

## 开始之前

- **录像**：录屏、摄像头录像，或者两路分开的文件。两路文件时千剪（Reelfold）会按声音自动对齐，不需要同时开录。
- **学生**：学生的名字和脸不该出现在公开的视频里。点到名字的句子会先列给你确认；脸可以用遮脸选项（见下）盖住，或先把录像裁掉。
- **翻译模型**（双语字幕需要，默认开启）：翻译走你的 AI 路由（任务 `translate`）。没有配置的话，字幕请选只要原文。

## 在 Mac 应用里

1. 首页选 **课堂切成知识点**（或直接说「把这节课切成知识点，中英双语字幕，再出一份学习笔记」），把录像拖进来，有摄像头文件也一起拖。
2. **方案**写明用哪个配方、版式（有摄像头时默认画中画）、字幕方式和发布平台。
3. **审核知识点**。千剪只转写一遍，列出找到的知识点：类型、起止时间、标题、释义、关键词。可以改、删或保留。
4. 渲染：每个知识点按每种平台画幅各出一条（9:16 和 16:9 分开渲染，之后不会再被裁），再加回顾和学习笔记。
5. **审片发布**。给你看之前每个文件都检查过（有声音、响度、第一帧、字幕、封面），有红灯就不会默认通过。

## 用 Claude Code 技能

技能按 `workflows/lesson-clips` 来做：

```bash
python -m vstudio.lesson plan --source lesson.mp4 --out work/points.json --count 6
python -m vstudio.lesson sync --source lesson.mp4 --camera cam.mov --out work/sync.json     # 只有两路文件时
python -m vstudio.lesson render work/points.json --source lesson.mp4 --camera cam.mov --sync work/sync.json \
    --layout pip --platforms xiaohongshu:full,douyin --subtitles bilingual --recap --out out
python -m vstudio.lesson notes work/points.json --out out/notes.md --pdf out/notes.pdf --title "职场寒暄"
```

## 一条切片里有什么

| 部分 | 内容 |
|---|---|
| 标题卡（2.2 秒） | 类型（「Today's phrase · 今日短语」）、短语或要点、另一种语言的释义。同时也是封面。 |
| 讲解 | 老师原速的那一段，上方一直显示这个知识点。 |
| 关键词卡片 | 关键词第一次说出来时，显示几秒词和释义。 |
| 字幕 | 说的那句话，目标短语高亮；下面一行小字是译文。 |

知识点分四类：**短语**、**词汇**、**知识点**（规则或区别）、**易错点**（常见错误和正确说法）。例句会归到它所说明的那个知识点里。

## 有摄像头文件时的版式

| 版式 | 效果 |
|---|---|
| `screen` | 只看屏幕。 |
| `pip` | 屏幕 + 右下角小窗摄像头（有摄像头时默认）。 |
| `band` | 竖屏：上面屏幕、下面摄像头；横屏：屏幕 + 右侧摄像头一栏。 |
| `camera` | 只看摄像头。 |

两路录像按声音对不上时，会停下来请你给出时间差，而不是瞎猜。

## 常用选项

| 选项 | 默认 | 作用 |
|---|---|---|
| 字幕 | 双语 | `bilingual` 双语、`mono` 只要原文、`translated` 只要译文。 |
| 翻译成 | 自动 | 中英互译；也可以指定。 |
| 知识点条数 | 6 | 切几个知识点，每条 20 到 90 秒。 |
| 语速 | 1.0 | 语言课保持原速。 |
| 遮脸 | 不遮 | `sticker` 贴纸或 `blur` 模糊，可选整个画面、摄像头小窗或屏幕。不到一半的帧找到脸会亮红灯。 |
| 本课回顾 | 开 | 一条回顾：每个知识点一张小卡片加老师的原话。 |

## 示例指令

- 「把这节课切成知识点，每条一个短语，中英双语字幕，再出一份学习笔记」
- 「英语课切成今日短语，只要中文字幕」
- 「录屏和摄像头是两个文件：画中画，把我的脸遮一下」
