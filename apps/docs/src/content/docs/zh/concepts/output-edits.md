成片二次编辑让你在视频渲染完之后继续改，不用把项目从头再跑一遍。千剪（Reelfold）里显示的任何成片都可以：配方项目导出的文件，或者技能做出来的文件夹里的成片。

## 为什么重要

大部分修改是看完成片才想到的：删掉一句、改字幕里的一个名字、加一个竖屏版本、再快一点。这些改动都很小，也应该很便宜。二次编辑把每一步都记成可撤销的历史，从不覆盖原文件，并且只重新渲染受影响的部分。

## 怎么运作

### 两种模式

| 模式 | 什么时候 | 字幕能怎么改 |
|---|---|---|
| 管线模式 | 千剪保留了这条视频的干净母版（没烧字幕）和字幕时间轴 | 字幕完全可改：文字、样式、位置、关键词颜色、开关。其他比例从母版重新做人脸跟踪构图 |
| 已合成模式 | 只有成片文件 | 改动叠加在成片上。字幕只能新增（用遮罩盖住原来烧进去的字幕，或用上下留条的版式），烧进去的文字不能改样式 |

编辑器会告诉你这条视频是哪种模式，某个选项为什么不可用。

### 能改什么

| 改动 | 说明 |
|---|---|
| 掐头去尾、剪掉一段 | 转写过一次之后（会缓存），剪辑点自动对齐到完整的词 |
| 速度 | 0.5× 到 2.5×，保持音调 |
| 响度 | 默认用目标平台的标准 |
| 字幕 | 改文字、改样式、增删字幕。改原有字幕时必须和音频一致 |
| 标题条 | 添加、修改或去掉 |
| 主题 | 一步换掉整体视觉（见[主题](/docs/zh/concepts/themes/)） |
| 特效 | 20 种：弹出大字、印章、推镜放大、金句卡、章节卡、标注气泡、记笔记面板、贴纸、角标、框选高亮、进度条、马克笔划重点、章节细线、数字滚动、人名条、音效、背景音乐、转场、结尾淡出、调色 |
| 封面 | 选一帧，配上文字 |
| 改比例 | 加 3:4、9:16、16:9 或某个平台版本，用设计过的版式，不是简单加黑边 |
| 还原 | 回到原始状态，这一步也可撤销 |

### 用一句话改

直接打字说要什么（「这段剪掉」「字幕大一点」「加个进度条」）。你选的 AI 模型会提出具体的编辑步骤，每一步都过一遍和手动编辑相同的校验，编出来的特效或越界的数值会被去掉。你确认之前什么都不会变。你可以先在时间轴上选一段、选一句字幕或一个特效，这时「这段」「这里」就指它。没配置模型时，少数直白的说法也能用（调速、掐头去尾、导出平台版本、响度、进度条、淡出）。

项目级的要求（「把所有视频里的系列标签去掉」）会一次发给所有成片。烧进已合成成片里的文字，编辑器没法去掉，这些视频会被标记为需要重新渲染，并告诉你该改哪些文件。

### 撤销、单步还原和对话记录

每次修改是一个撤销步骤。单步还原可以只取消之前的某一步，保留它之后的所有修改；如果后面的步骤依赖它，会提示你改用撤销。每条成片有自己的对话记录（你的要求、AI 的提议、用的模型、花费），之后打开还能看到改过什么。

### 预览

预览用低码率快速渲染，正式导出用平台的交付编码。每一段结果都有缓存，改一句字幕只重跑最后一步。还没应用的改动，也可以先渲染一个前后对比预览。

## 在 Mac App 里

在项目里打开任意一条成片，手动改，或者在它的对话框里打字。

## 用 Claude Code 技能

直接跟 Claude 说要怎么改成片，比如「把第二句剪掉，再出一个横屏版」「字幕换成白字，关键词标黄」。底层命令是 `python -m vstudio.project output show / edit / render / undo / revert / ai / chat / effects`。
