主题用一个名字概括一条视频里所有图形元素的样子：纸色和墨色、唯一的强调色、关键词怎么突出、字体、圆角、阴影，以及元素怎么动。标题条、纸色字幕条、记笔记卡片、金句卡、印章、弹出大字、进度条，以及其他跟随主题的特效，读的都是同一套主题。

## 为什么重要

视频看起来「讲究」，很大程度靠的是统一。用同一个主题，笔记卡、标题和进度条之间永远协调，一条是这样，一百条也是这样。换风格是一个决定，而不是二十次调色。

## 五个主题

| 主题 | 样子 | 适合 |
|---|---|---|
| `editorial` 编辑感（默认） | 暖白纸、深墨色、一点赤陶色；标题和金句用宋体；关键词带柔和的马克笔底色 | 大多数口播、复盘、干货。最稳妥的高级感 |
| `mono` 黑白灰 | 中性纸色、近黑墨色、一支淡黄马克笔，没有彩色强调 | 观点、科技、干货，颜色会分散注意力的内容 |
| `soft` 低饱和柔和 | 石灰白、鼠尾草绿，圆角更大，阴影更轻 | 生活方式、温和的分享 |
| `night` 夜间 | 深炭色底、暖象牙色字、琥珀色强调；关键词直接用琥珀色 | 夜聊、情绪向、暗调素材 |
| `xhs-pop` 小红书红（克制版） | 保留小红书红，但只给一个关键词用；白卡片、细线 | 想要平台原生红色的时候 |

另外还有 `classic`（旧版），是有主题之前的样子。保留它只是为了老设置不突然变样，不会作为新风格推荐。

## 所有主题都遵守的规则

- **每一帧只有一个强调色。** 强调色只标一样东西：一条短线、一个圆点、进度条的填充、一个关键词。不会用来铺满半个标题或做框线。
- **每行最多强调一个关键词。** 同一行里多出来的 `【关键词】` 按普通文字显示。
- **浅色纸上不用高饱和红。** 只有 `xhs-pop` 用红色，而且是更深的红，只给一个关键词。
- **笔记是纸，不是仪表盘。** 浅色卡片、小标签、一条细线，然后是内容。
- **金句靠排版。** 靠字重和字号区分层次，不用彩色的卡通引号。
- **印章和弹出大字要克制。** 200 到 350 毫秒的淡入上浮，缓出；除了 `xhs-pop`，不砸入、不倾斜。
- **字幕对比度至少 4.5:1。** 每个主题都有测试检查。
- **进度条是一条细线。** 细轨道加强调色填充，没有圆钮，不发光。

字体只用开源授权的思源黑体和思源宋体（Noto Sans SC / Noto Serif SC）。

## 主题怎么确定

按顺序，先设了哪个就用哪个：

1. 对成片做的「换主题」编辑
2. 环境变量 `VSTUDIO_THEME`
3. 项目或配方的 `theme` 设置
4. 客户的 `theme`（接单做客户的活时）
5. 你 persona 里的 `style.theme`
6. `editorial`

每一层都可以只微调主题而不整个替换，比如在 `editorial` 上换成你自己的强调色。你给单个元素手动设的颜色（某个特效的颜色、字幕高亮色）永远优先于主题；做一次「换主题」编辑，会把这些颜色交还给主题。

## 特效也跟随主题

每个跟随主题的特效都从当前主题取颜色、字体、形状和动效。新特效也按这个方式写：用主题里的取值，不写死颜色，另外提供一个可选的颜色参数用于个别覆盖。

## 在 Mac App 里和用技能

在 persona 里用 `style.theme` 设一次默认主题。想给成片换风格，直接说：「换成更高级的配色」「换成黑白」「夜间模式」「红色太丑了」。这会变成一次「换主题」编辑，一步完成，可以撤销。
