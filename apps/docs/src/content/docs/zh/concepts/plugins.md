Reelfold 是视频制作的批量调度台：规划系列、维护分镜、给每个镜头报价、并行跑任务、检查结果，再交给你审。真正出画面的工具，以及驱动这些工具的 Agent，都以插件接入。

## 三类插件

| 类型 | 做什么 | 内置 |
|---|---|---|
| 导入器 | 把外部分镜或项目导入为镜头 | HyperFrames 项目、镜头表（JSON、CSV、Markdown）、EDL、OpenTimelineIO、Premiere / Final Cut XML |
| 镜头提供方 | 制作镜头 | 可灵、MiniMax 海螺、Veo、Seedance、即梦（你自己点生成）、HyperFrames 渲染 |
| Agent 执行器 | 把一个镜头的任务文件夹交给 Agent 或命令 | Claude Code、Codex、任意命令 |

在 **设置 › 视频生成 › 插件** 里能看到全部插件：开关、版本、权限和费用。

## 导入分镜

在创作页点 **导入分镜…**（或把文件 / 文件夹拖到输入框上），Reelfold 读取后直接打开新剧集的分镜。在某一集的分镜页点 **导入分镜…** 会替换当前镜头（会先确认；已经做好的素材仍保留在磁盘上）。

HyperFrames 项目的每个分镜帧变成一个镜头，带时长、画面、旁白和备注；有合成文件的帧会设为在本机用 HyperFrames 渲染。

## 用插件和 Agent 制作镜头

在镜头的来源菜单里选插件或 Agent（或在镜头表里写 `source` 列），然后点 **制作**。每个镜头有自己的任务文件夹，里面有说明、分镜画面和系列规则；多个镜头并行。任务文件夹里有可播放的视频或图片才算完成，随后成为一个素材版本。失败和需要你处理的镜头会出现在制作中和收件箱里。

## 费用

任何收费的生成都必须经过花费确认（预估、确认码、预算、月度上限）。用你自己 Claude Code / Codex 订阅的 Agent、在本机运行的工具，Reelfold 不收费；收费插件只能经过花费确认后运行。

## 添加自己的插件

在 `~/.config/vstudio/plugins/` 里放一个带 `plugin.yaml` 的文件夹，新插件默认关闭。完整约定（清单、分镜格式、任务文件夹协议、权限、费用）见仓库里的 `docs/PLUGINS.md`。
